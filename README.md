# Aplikasi Deteksi Emosi (Emotion Detection Application)

Aplikasi ini dibuat menggunakan pustaka Watson NLP berbasis Python dan framework Flask untuk mendeteksi emosi dari teks input. Aplikasi ini dapat menganalisis beberapa emosi seperti marah (anger), jijik (disgust), takut (fear), senang (joy), dan sedih (sadness), serta menentukan emosi dominan dari teks tersebut.

## Fitur Utama
* Deteksi Emosi berbasis Watson NLP Runtime API
* Antarmuka Web menggunakan Flask
* Pengujian Unit (Unit Testing) otomatis
* Analisis kode statis dengan Pylint (Skor 10/10)
